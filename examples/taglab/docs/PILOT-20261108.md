# 2026-11-08 小样本 A/B 实验记录

这轮运行用于检查流程和寻找问题。原始语料、个人标签、密钥及完整模型输出保留在本机。

## 实验设置

查看输出前，按已有 ID 顺序固定 pilot 前 10 条。对配置的 `qwen3.8-flash` 模型分别执行 A/B，共 20 次请求。A 提供标签 ID 和名称，B 增加定义、反例和规则。

共同条件为 JSON / 连续原文协议、temperature=0.2、最多 1,200 输出 token、关闭思考模式。未自动重试，未使用留出集。每条固定先 A 后 B，没有做随机调用顺序或重复采样性能实验。

原实验保存了 4 条运行时参考。它们来自单人标注，其中两条经过助手依据复核，不构成独立双人共识。后续审查发现一条原参考的标签依据存在疑问，按用户确认另做修订；原实验和旧分数没有覆盖。

两组均通过机械校验的 8 条记录中，5 条主题集合或形式不同。分歧用于选择复核案例，不能直接认定谁错。

## 失败与处理

- B 把多段原文用省略号连成引用。系统拒绝并保留原输出、用量与错误，没有自动改写后算作成功。
- A 填写了独白形式与空引用，解释里却说应为无法判断。校验以实际字段为准，没有根据解释偷偷修正。
- 两条 B 输出引用了真实文字，但未明确证明讲话人数；它们通过字符串校验，也没有自行请求复核。
- 对一条人工参考的标签依据单独记录疑问，没有直接把两个模型都与参考不同视为模型错误，也没有自动改参考来提高分数。

两条语义支持案例进入独立的 Argilla review 数据集。初次 SDK 回读确认 2 条记录、4 个机器 Suggestions、0 个用户 Responses；网页显示机器来源和单独的语义支持问题。后续用户提交保留了相同的来源区分。

## 后续反馈与参考修订

用户选择保留两条“独白”意见，但标记争议，不作为独立评分参考。原始回答和说明先归档，再记录最终确认。一条引用末尾带多余空白，只在清理边界后能精确匹配原文时规范化，并保存前后值；内部内容和模型校验规则不变。

用户另明确取消了原参考中的一个生活方式标签。保持预测不变，单独复算后，A 的主题 F1 从 0.875 变为 0.933，B 从 0.769 变为 0.833，仍各使用 4 条有效参考；完全匹配都从 2/4 变为 3/4。原实验和导出快照哈希未变，新增模型调用为 0。

**分数变化来自参考修订，不能解释为模型变强，也不是新的独立测试集成绩。** 原实验的 18/20 机械通过率没有改变。

`workbench/reference_audit.py` 检查输入和规范是否一致，另存带来源指纹的分析。当前 40 项测试包含争议参考排除、模型可见反馈不得晋升独立参考等检查。

本地仍为 7 条人工参考和 8 次实验。参考分析独立保存，不算成第 9 次模型运行。下一步是在已保存的结果上演示与复盘，再逐步补充不同类别和独立标注者的参考。
